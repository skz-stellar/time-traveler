# Repository instructions

- Do not add AI credits, AI co-authors, generated-by notices, or AI attribution
  trailers to commit messages, pull requests, documentation, or source files.
- Use the user's Git identity; do not invent co-authors or bypass commit hooks.
- Keep conversion entirely in the browser. Store only the timezone preference,
  never timestamps or conversion history. Do not add network dependencies.
- Preserve the default America/Phoenix timezone (MST, UTC−07:00 year-round).
- Run `npm test` for changes to parsing, timezone conversion, or preferences.
